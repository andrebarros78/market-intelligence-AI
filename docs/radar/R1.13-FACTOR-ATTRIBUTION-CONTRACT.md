# R1.13 — Atribuição automática de fatores observáveis

Objetivo: estimar quanto fatores observáveis historicamente associados ao indicador podem explicar da mudança atual, sem declarar causalidade.

Regras: usar apenas histórico anterior para ajustar a relação; exigir histórico mínimo e associação mínima; rejeitar candidatos inelegíveis ou historicamente instáveis; registrar contribuição estimada, força da associação e resíduo não explicado; marcar a saída como inferência; preservar `residual_analysis` manual como compatibilidade.

Critério de conclusão: unidade + API + Temporal + PostgreSQL + deduplicação + migrations + CI completo verdes.
